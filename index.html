About Me

I turn ideas into clear, responsive web experiences. This portfolio brings together my work in HTML, CSS, JavaScript and Vue.js across the Red & Yellow Front-End Web Development course.

Hi, I'm James Taljaard.

I built this portfolio to show both the work I have produced and the thinking behind it. My approach starts with a clear structure, develops through consistent visual design, and uses interaction where it makes a page easier to use.

Across the course, I worked from semantic HTML and responsive CSS through to JavaScript validation, reusable Vue components and client-side routing. Each project gave me a practical way to connect a new technique to a real interface.

From structure to interaction

HTML provides the meaning and structure. CSS Grid, Flexbox and media queries keep the layouts usable across screen sizes. JavaScript adds useful behaviour, including project filtering, clear form feedback and a confirmation dialog.

I pay attention to the details that make these features usable: descriptive links, visible keyboard focus, associated form labels and readable content.

Bringing my skills together

This final showcase is a multi-page website built with HTML, CSS and JavaScript. The Projects page also links to my earlier Vue.js and Vue Router assignments, showing how the same portfolio developed across different approaches.

The result is a focused personal portfolio: consistent in its design, purposeful in its interactions and straightforward to explore.
